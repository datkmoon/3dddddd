# 🛠️ Live Site Builder — مولّد المواقع الحية

موقع كامل بصفحة واحدة يبنيه **20 مؤشر (cursor) بذيول تشبه الأفعى** بشكل حي أمام عينك، بمحتوى حقيقي مباشر من **ويكيبيديا العربية** وصور حقيقية من **ويكيميديا كومنز** — والآن **بأصوات حية مولّدة محلياً**.

## ⚙️ خياران في البداية
- **🌐 خيار 1 — موقع عن أي موضوع**: اكتب أي موضوع (أو گِل بصوتك 🎤) وسيبنيه لك بمعلومات ويكيبيديا الحقيقية.
- **⚽ خيار 2 — وضع النجوم**: تصميم مخصص كامل عن **كريستيانو رونالدو** (أسود × ذهبي × أبيض) أو **ليونيل ميسي** (أزرق أرجنتيني × ذهبي).

## 🔊 نظام الصوت الحي (Web Audio API — بدون أي ملفات خارجية)
- طقّات لوحة مفاتيح أثناء الكتابة · نقرة · حفيف سحب الصور · إفلات · رنّة إنجاز كل مهمة · طقعة الختم · فانفير الاكتمال
- زر كتم/تشغيل يحفظ تفضيلك بالمتصفح

## 🎮 التحكم الكامل
- 🔊 **صوت** · ⏸️ **إيقاف مؤقت** (يجمّد البناء كله ويكمل من نفس النقطة) · 👂 **اسمع** (قارئ صوتي عربي يقرأ محتوى الموقع) · ⚡ **سرعة ×1/×2/×3** · ⏭ **إنهاء فوري** · 🎨 **3 ألوان حرة** · 📄 **PDF** · 🌙 **ليلي**
- ⌨️ **اختصارات كيبورد**: S صوت · SPACE إيقاف · X اسمع · F إنهاء · T ألوان · P بدي إف · D ليلي

## 🚀 تشغيل الموقع (GitHub Pages)
1. **Settings → Pages** → **Deploy from a branch** → الفرع `main` والمجلد `/ (root)`
2. بعد دقايق: **https://datkmoon.github.io/3dddddd/**

أو نزّل `index.html` وافتحه مباشرة بالمتصفح — كل شي بملف واحد.
