# 🛠️ Live Site Builder — مولّد المواقع الحية

موقع كامل بصفحة واحدة يبنيه **20 مؤشر (cursor) بذيول تشبه الأفعى** بشكل حي أمام عينك، بمحتوى حقيقي مباشر من **ويكيبيديا العربية** وصور حقيقية من **ويكيميديا كومنز**.

## ✨ المميزات
- 🎤 **بحث صوتي**: اضغط زر المايك وگِل الموضوع بصوتك — المحرك يسمعك ويبني الموقع فوراً (عربي، دعم متصفحات Chrome/Edge/Safari).
- 🎨 **منتقي 3 ألوان**: اختر أي 3 ألوان تخطر على بالك (أي لون حر عبر color picker) وتتغير كلها فوراً، وتنحفظ بالمتصفح تلقائيًا + 6 قوالب جاهزة وزر عشوائي.
- 📝 **أي موضوع**: اكتب أي موضوع بالعالمي واضغط «جهّز» — المحرك يجيب المقالة الحقيقية من ويكيبيديا العربية ويبني الموقع منها.
- 🖼️ **30+ صورة حقيقية** من ويكيميديا كومنز لكل صفحة، مع اسم ووصف حقيقي تحت كل صورة، بدون تكرار.
- ⏱️ **مؤقت البناء**: عند الاكتمال تظهر لك المدة الفعلية «اكتمل البناء بـ X ثانية».
- 📄 **تصدير PDF** صفحة بصفحة بجودة عالية.
- 🧠 محرك حي: كتابة، سحب عناصر، شرارات، أختام — كل شي يُبنى قدامك.
- 🏷️ من صنع: **@964.wt**

## 🚀 تشغيل الموقع (GitHub Pages)
1. افتح إعدادات المستودع → **Settings → Pages**
2. اختر **Deploy from a branch** → الفرع `main` والمجلد `/ (root)`
3. بعد دقايق يشتغل الرابط: **https://datkmoon.github.io/3dddddd/**

أو نزّل `index.html` وافتحه مباشرة بالمتصفح — كل شي بملف واحد.
