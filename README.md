# 🛠️ Live Site Builder — مولّد المواقع الحية

موقع كامل بصفحة واحدة يبنيه **20 مؤشر (cursor) بذيول تشبه الأفعى** بشكل حي أمام عينك، بمحتوى حقيقي مباشر من **ويكيبيديا العربية** وصور حقيقية من **ويكيميديا كومنز**.

## ⚙️ خياران في البداية
- **🌐 خيار 1 — موقع عن أي موضوع**: اكتب أي موضوع (أو گِل بصوتك 🎤) وسيبنيه لك بمعلومات ويكيبيديا الحقيقية.
- **⚽ خيار 2 — وضع النجوم**: تصميم مخصص كامل عن **كريستيانو رونالدو** (بألوانه: أسود × ذهبي × أبيض) أو **ليونيل ميسي** (بالأزرق الأرجنتيني × الذهبي) — مسيرة كاملة، بطولات، أرقام قياسية، وصور حقيقية.

## ✨ المميزات
- 🎤 **بحث صوتي**: زر المايك — گِل الموضوع بصوتك وسيبنيه فوراً.
- 🎨 **منتقي 3 ألوان**: أي 3 ألوان تتطبق فوراً وتنحفظ بالمتصفح + 6 قوالب جاهزة.
- ⏱️ **مؤقت البناء**: تظهر مدة البناء الفعلية عند الاكتمال.
- 🖼️ **30+ صورة حقيقية** من ويكيميديا كومنز مع اسم ووصف حقيقي تحت كل صورة.
- 📄 **تصدير PDF** صفحة بصفحة بجودة عالية.
- 🧠 محرك حي: كتابة، سحب عناصر، شرارات، أختام.
- 🏷️ من صنع: **@964.wt**

## 🚀 تشغيل الموقع (GitHub Pages)
1. **Settings → Pages** → **Deploy from a branch** → الفرع `main` والمجلد `/ (root)`
2. بعد دقايق: **https://datkmoon.github.io/3dddddd/**

أو نزّل `index.html` وافتحه مباشرة بالمتصفح — كل شي بملف واحد.
